# Soccer Player Database

Edit, change, and explore this soccer database by finding rankings, stats, and more.
##  Calculations
- After selecting the rankings, it will go through every player's stats, add their goals and assists, find their average goals and assists per 90min, and then rank them using lambda.
- There is an average goals per team option where it finds all the players who share a team and adds up their goals and divides them by the number of players that are there to find the average goals per team average
- There is an average minutes per match option where it calculates the average minutes a player played per match.
